# Oceanography with Flowers

## Introduction

Flowers is a novel machine learning architecture which uses warp drives to efficiently solve PDEs of many kinds. To show its usage in the real world, I am comparing how it performs against state of the art physics-informed  models by predicting large simulation data of the Pacific Ocean.

## Structure

The the training pipeline can be found under `oceanography_with_flowers` directly while the models can be found under `oceanography_with_flowers/model`
